### USUARIO — `/api/usuarios`
| Endpoint | Método | Descripción |
|----------|--------|-------------|
| `/api/usuarios/registro` | POST | Crea usuario. Valida campos obligatorios y formato email. HTTP 201. |
| `/api/usuarios/login` | POST | Autentica por email+password. HTTP 200. |
| `/api/usuarios/{id}` | GET | Busca usuario por ID. HTTP 404 si no existe. |
| `/api/usuarios` | GET | Lista todos los usuarios. |
| `/api/usuarios/{id}` | DELETE | Elimina usuario. HTTP 204. |

### HABITACIÓN — `/api/habitaciones`
| Endpoint | Método | Descripción |
|----------|--------|-------------|
| `/api/habitaciones` | POST | Crea habitación. HTTP 201. |
| `/api/habitaciones/{id}` | GET | Obtiene habitación por ID. |
| `/api/habitaciones` | GET | Lista todas. |
| `/api/habitaciones/{id}` | PUT | Actualiza habitación. |
| `/api/habitaciones/{id}` | DELETE | Elimina habitación. HTTP 204. |
| `/api/habitaciones/disponibles?tipo=` | GET | Filtra disponibles por tipo (SIMPLE/DOBLE/SUITE). |
| `/api/habitaciones/disponibles/precio?max=` | GET | Filtra disponibles por precio máximo. |
| `/api/habitaciones/disponibles/capacidad?personas=` | GET | Filtra disponibles por capacidad. |

### RESERVA — `/api/reservas`
| Endpoint | Método | Descripción |
|----------|--------|-------------|
| `/api/reservas` | POST | Crea reserva. Valida: habitación DISPONIBLE, fechas válidas, sin solapamiento. Calcula total. HTTP 201. |
| `/api/reservas/{id}/cancelar` | PUT | Cancela reserva. HTTP 200. |
| `/api/reservas/{id}` | GET | Obtiene reserva por ID. |
| `/api/reservas` | GET | Lista todas. Filtra por ?habitacionId=. |
| `/api/reservas/estadisticas/ocupadas?fecha=` | GET | Cuenta ocupadas en fecha. |
| `/api/reservas/estadisticas/ingresos-por-mes` | GET | Ingresos agrupados por mes. |
| `/api/reservas/estadisticas/ocupacion-por-mes` | GET | Reservas agrupadas por mes. |
| `/api/reservas/estadisticas/tendencia?desde=` | GET | Tendencia diaria desde fecha. |
| `/api/reservas/estadisticas/habitaciones-mas-reservadas` | GET | Ranking de habitaciones más reservadas. |
